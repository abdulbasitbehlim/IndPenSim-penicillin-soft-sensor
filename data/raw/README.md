# Original full dataset

The original file is named 100_Batches_IndPenSim_V3.csv. Download it from the [IndPenSim dataset record](https://doi.org/10.17632/pdnjz7zz5x.1) and place it here when running the earlier baseline notebook.

The supplied archives contain the four [process-data split CSVs](../splits/README.md), not this full process-plus-Raman CSV. The split files are already included and are sufficient as input to main.ipynb.
